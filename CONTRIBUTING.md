# Contributing to SBC-Context-Router



First off, thank you for considering contributing to `SBC-Context-Router`! Contributions from the telecommunications and software engineering community help keep this project secure, scalable, and robust.



## Code of Conduct

By participating, you agree to maintain a professional, respectful, and collaborative environment for all developers and contributors.



## How to Contribute



1. **Fork the Repository**  
Click the **Fork** button at the top right of the repository page to create a personal copy of the project.


2. **Create a Feature Branch**
Create a descriptive branch for your changes:

```bash
    git checkout -b feature/your-feature-name
